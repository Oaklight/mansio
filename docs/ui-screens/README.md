# Admin console screenshots

Evidence snapshots from the M4b redesign, captured with headless Chromium
against a local `AdminServer` seeded with demo messages and one token.
They are documentation, not tests: the Playwright run is described in the
PR that introduced them.

- `overview-1280.jpg`, `overview-400.jpg` — stat cards, throughput chart,
  channel breakdown.
- `channel-detail-1280.jpg`, `channel-detail-400.jpg` — channel list with
  the detail pane (desktop) and the full-width detail overlay (mobile).
- `messages-1280.jpg` — routed message list with the pinned composer.
- `user-detail-1280.jpg` — a user's tokens and presence in the detail pane.
- `tokens-1280.jpg` — token table with rotate/delete actions.
- `system-1280.jpg` — version, backend and token counters.
